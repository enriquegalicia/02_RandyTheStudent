
### Description
```text
RandoSquad takes the guesswork out of grouping students and calling on them fairly.

Add your roster once, then let RandoSquad do the rest:

RANDOM, BALANCED GROUPS
Generate 2 to 6 groups in one tap. RandoSquad looks at each student's history — who's grouped with whom, and who's held which role — and balances new groups against it, so the same pairings and the same roles don't repeat activity after activity.

FAIR PARTICIPATION, NO FAVORITES
Pick a student to answer with one tap. RandoSquad weights the pick toward whoever has participated the least, so quieter students get called on too — and you can log every pick to keep a running participation count per student.

GRADE BY GROUP
Save any group set as a named activity, then grade each group directly. Every grade rolls up into simple charts so you can see performance by activity or by student at a glance.

BUILT FOR IPHONE AND IPAD
One roster, one set of groups, laid out properly on whatever device you grab — phone in your pocket between classes, iPad on your desk during one.

PRIVATE BY DESIGN
Everything lives on your device. No account, no sign-in, no ads, no tracking, no internet connection required. Your roster is yours.

Whether you're running small-group discussions, lab partners, project teams, or just making sure every student gets a fair shot to answer, RandoSquad keeps it quick, fair, and simple.
```

### Notes
```text
RandoSquad is a classroom tool for teachers. No account, no network access and no purchases; everything stays on the device.

1. On the first screen, type a class name under "New class name", tap Add, and open the class. Roster tab: add a few students by hand, or Import CSV (Get CSV Template shows the format).
2. Groups tab: choose 2 to 6 groups and tap Generate Groups. Groups are balanced against each student's earlier groupings and roles.
3. Participation tab: "Pick a Student" chooses who answers next, weighted toward whoever has participated least.
4. Activities tab: save a group set as an activity and grade each group; Stats charts the grades by activity or by student.

This update changes the look only (a new app icon and new colors in the app); no feature changed.
```
